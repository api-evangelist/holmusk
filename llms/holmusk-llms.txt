# Holmusk

> Holmusk is a health data science company building real-world evidence (RWE) infrastructure for
> neuropsychiatry and behavioral health. Its NeuroBlu product pairs a de-identified, NLP-enriched
> longitudinal dataset of 46.5M+ US patients over 20+ years with a hosted analytics platform
> (Cohort Explorer, Data Explorer, Category Mapper, and an in-platform R / Python / SQL code
> studio). Headquartered in Singapore, with offices in New York, London and Basel.
>
> IMPORTANT FOR AGENTS: Holmusk publishes NO public API. As of 2026-08-22 there is no developer
> portal, no API reference, no OpenAPI/AsyncAPI/GraphQL/gRPC/SOAP contract, no SDK, no MCP server
> and no A2A agent card on any Holmusk or NeuroBlu host. Access to NeuroBlu Data and NeuroBlu
> Analytics is by commercial agreement and login only. Do not attempt to construct calls against
> app.neuroblu.ai — its /api/* paths are the web application's own authenticated XHR layer, are
> undocumented, and are not offered as an integration surface.
>
> This file was GENERATED by API Evangelist from published Holmusk material; it is not published
> by Holmusk. Source of truth is https://www.holmusk.com/ and https://www.neuroblu.ai/.

## Products
- [NeuroBlu Data](https://www.holmusk.com/solutions): De-identified real-world behavioral health data — 46.5M+ patients, 50 states, 20+ years; diagnoses, prescriptions, hospitalizations, demographics, procedures, outcome measures, plus NLP-derived labels from clinical notes.
- [NeuroBlu Analytics](https://www.neuroblu.ai/solutions): Hosted research platform — Data Explorer, Cohort Explorer, Category Mapper, SQL Studio, Code Studio (R / Python), Symptom Intelligence, Reports (beta).
- [NeuroBlu Analytics application](https://app.neuroblu.ai/): Customer login. Enterprise SSO since v4.6.
